# Packed-index optimization rig

Durable protocols, raw observations, source decisions and limitations are in [the research record](../../Research/2026-10-19-binary-packed/REPORT.md). The comparison exports distinguish the immutable packed class from the existing mutable class. They do not represent automatic backend dispatch or a published package/website update.

The rig uses exact retained fixture bytes, validates all result IDs, materializes and consumes matches, serializes measurement under `Global\Tedd.RTree.PerformanceHost`, and retains every observation. Private scratch, builds and the optional DotNetLab catalog use `D:\Workspaces\AI\rtree-binary-20261019`. Reproduction must use a separate evidence destination; existing epoch directories deliberately reject replacement.

Source progression is explicit:

- `study.py`: binary partition, owned-buffer, SIMD encoding, traversal, output-buffer, predicate, bounds-reduction and normalized-layout studies.
- `finish.py`: cleaned repository-SDK source, original/held-out/interface oracles and first independent confirmation.
- `boundary.py`, `promote.py`: recursive-inlining boundary and independent regime checks.
- `jitpolicy.py`, `promote_policy.py`: local query JIT-policy comparison and independent confirmation.
- `compare.py`: fresh complete seven-competitor matrix, keeping direct/interop and list/visitor modes separate in raw data.
- `integrate.py`: hash-bound review patch and prospective adoption guards; local source application is separate from measurement.
- `profile.py`: two owned DotNetLab captures after quiet timing, with a task-local SQLite catalog and scoped observation grants.
- `results.py`, `archive.py`: complete-cell exports, raw-log audit and verified source/binary archive before cleanup.

Quiet timing and diagnostic runs are separate. Batch means do not establish individual latency percentiles; process repetitions do not establish independence. CPU frequency, thermals and unrelated desktop activity remain uncontrolled. Native allocation is unavailable; native construction includes destruction while managed allocation/GC and retained output follow the declared caller contract. NTS visitor is the disclosed nonmaterializing API exception. SharpTrees remains unranked after its retained correctness failure.

The binary partition prototypes were adapted from the pinned `static_aabb2d_index` source retained in the reproduction archive. They are not the previously tested stable 256-bucket MSD sort, and are not selected merely because the Rust implementation uses them. The Hilbert transform follows the public-domain algorithm already attributed in the library.
